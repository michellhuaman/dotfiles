#   <key URL> <file name in /etc/pki/rpm-gpg/> [fingerprint]
# rpm-ostree doesn't download gpgkey=https:// URLs the way dnf does, so the
# keys are saved locally and each repo file points at them with
# gpgkey=file:///etc/pki/rpm-gpg/<file name>.
# With a fingerprint, setup.sh stops if the downloaded key doesn't match it.

# Signing keys for the repos in ubuntu/repos/, one per line:
#   <key URL> <file name in /usr/share/keyrings/> [fingerprint]
# The file name must match the repo file's Signed-By (signed-by=) path.
# A .gpg name gets a binary key (text keys are converted, as the docs do);
# an .asc name keeps the key as text. With a fingerprint, setup.sh stops if
# the downloaded key doesn't match it.
